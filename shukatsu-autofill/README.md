# 就活マイページ自動入力（Chrome 拡張機能）

就活サイトのマイページ登録フォームに、登録しておいたプロフィールを自動入力します。

| 区分 | 入力する項目 |
|---|---|
| 基本情報 | 漢字氏名・カナ氏名（ふりがな欄はひらがな）・ローマ字氏名・性別・生年月日 |
| 現住所 | 郵便番号（3桁+4桁にも対応）・都道府県・市区郡町村・町域番地・建物名 |
| 電話番号 | 自宅・携帯（3分割の欄にも対応） |
| 休暇中の連絡先 | 住所一式・電話番号。「現在の連絡先と同じ」チェックも自動でオン |
| メールアドレス | メールアドレス・確認用、メールアドレス2・確認用 |
| 学校情報 | 学校区分・設置区分・学校名の頭文字（学校名（カナ）の1文字）・学校名（検索結果の選択肢）・学部・学科・入学年月・卒業年月・ゼミ・サークル |
| 学校所在地 | 住所一式 |
| 卒業高校 | 都道府県・高校名の頭文字・高校名の一部（どちらも高校名（カナ）の1文字）・高校名（検索結果の選択肢）・学科（普通科など）・高校入学年月・高校卒業年月 |

入力しないもの: 障害の有無などのアンケート、学位、保護者・緊急連絡先、自己PRなどの自由記述欄、画面に表示されていない欄。

## 対応している採用サイト

実際の登録フォームの作りを確認して対応しています。

| サービス | 主な対応内容 |
|---|---|
| **axol**（axol.jp） | 学校検索（頭文字→学校→学部→学科の連動プルダウン）、年月プルダウン、卒業高校の検索 |
| **i-web**（i-webs.jp） | メールアドレスの「アカウント＠ドメイン」分割欄、全角指定の住所、「緊急連絡先（休暇期間中の滞在先）」、卒業見込みの選択 |
| **snar**（snar.jp） | 表形式の項目、サブメールの「再入力」欄、性別「無回答」、卒業区分（卒業予定／既卒）、帰省先住所と「同じ」チェック |
| **e2r**（e2r.jp） | ローマ字の大文字指定、全角指定の住所、「その他電話番号」、課程（学部／修士）、文理区分、「日本国内／海外」の選択 |

共通して、海外在住者向けの欄（「連絡先電話番号（海外）」など）には入力しません。
e2r の学校名は別ウィンドウの学校検索では選ばず、学校名・学部名・学科名の欄に直接入力します（サイトが検索からの選択を必須にしている場合は、検索ボタンから選び直してください）。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこの `shukatsu-autofill` フォルダを選ぶ
4. ツールバーのパズルアイコンからピン留めしておくと便利です

## 使い方

1. 拡張機能アイコン →「プロフィールを編集」で情報を登録して保存
2. 就活サイトの登録ページを開き、アイコン →「このページに自動入力」（または `Alt+Shift+F`）
3. 入力された項目は緑の枠で表示されます。**送信前に必ず内容を確認してください**（自動で送信はしません）
4. 学校名・高校名を「検索」で探す形式のサイトでは、頭文字（高校は「高校名の一部」）を入れた後に
   横の検索ボタンを自動で押し、検索結果から学校を選び、続けて学部・学科のプルダウンも選びます。
   年を選ぶと月が選べるようになる欄なども、数秒間ページの変化を待ちながら順に入力します
   （ページの変化が落ち着くと終了。最大でおよそ12秒）

## 郵便番号からの住所入力（設定画面）

設定画面で郵便番号を入れて「住所を自動入力」ボタンを押す（または郵便番号の欄で Enter）と、都道府県・市区郡町村・町域（と住所カナ）を自動で入れます。番地は続けて手で入力してください。
住所データは日本郵便の「郵便番号データ（住所の郵便番号・UTF-8形式）」を拡張機能に同梱したもの（`zipdata.json`）で、調べる時にインターネットには接続しません。
データは作成時点のものなので、新しい郵便番号が見つからない場合は手で入力してください。

### 学校検索が何画面かに分かれているサイト（snar・i-web など）

「自動入力」を押したあと約1分半は画面の変化を見守り、「次へ」を押して次の選択肢が出てきたら続けて選びます。
（学校区分 → 学校名の頭文字 → 学校 → 学部 → 文理区分 → 系統区分 の順に、設定に合うものを選択）

- 「次へ」は自動では押しません。自分で押してください
- 頭文字は濁点なしの50音表にも対応（「ド」→「と」）
- 学校区分が「私立大学」「国立大学院」のような形なら、設定の「設置区分」と「学校区分」を組み合わせて選びます
- 学校の所在地が都道府県や地方名（「近畿」など）で並んでいる場合は、設定の「学校所在地」の都道府県から選びます
- 自分で選び直した項目は、見守り中に元に戻しません

「次へ」で**ページごと切り替わる**サイトや、学校検索が**別ウィンドウで開く**サイト（i-web・e2r など）にも対応しています。
「自動入力」を押したタブと、そこから開いたウィンドウでは、30分間、新しい画面が開くたびに自動で入力・選択します
（i-web・snar・e2r・axol の4サイトだけ。ポップアップの「『次へ』や学校検索のウィンドウでも続けて入力」でオフにできます）。

i-web・snar の学校選択（学校区分・頭文字・所在地 → 学校 → 学部 → 学科・文理区分）では、その画面の項目が**全部選べたら「次へ」も自動で押します**。
名前・住所・パスワードなどを入力する画面や、自分で選ぶ項目（設定していない系統区分など）が残っている画面では押しません。

e2r の学校検索ウィンドウでは、学校種別 →「と」などの頭文字 → 学校名 → 学部 →「選択」→ 学科 →「選択」まで自動で進み、元の画面に学校・学部・学科が入ります。

## セキュリティ・プライバシー

- **保存場所はこのパソコンの Chrome の中だけ**です（`chrome.storage.local`）。Google アカウントへの同期（`storage.sync`）は使っていないので、他のパソコンや他人の環境には保存されません
- **インターネットへの通信を一切しません**。拡張機能のページはセキュリティ設定（CSP: `connect-src 'self'`）で、拡張機能の中のファイル以外への通信が禁止されています。外部サーバーもありません
- **普段はサイトを読み取る権限を持っていません**（`activeTab` のみ）。ボタンかショートカットを押したそのタブにだけ、その時だけ動きます。採用サイト4つ（i-web・snar・e2r・axol）だけは、自動入力を押したタブとそこから開いたウィンドウで、押してから30分間だけ続けて動きます（拡張機能を読み込む時に、この4サイトへの許可が表示されます）
- 入力処理はページ側のプログラムから隔離された環境で動くため、サイト側からプロフィール全体を読み取ることはできません。サイトに渡るのは実際に入力された欄の値だけです
- 画面外・極小・透明に隠された欄には入力しません（隠し欄で個人情報を抜き取る手口への対策）
- 設定画面の「登録内容をすべて削除」でいつでも消せます。拡張機能を削除した場合もデータは消えます
- 注意: 同じ Windows ユーザー・同じ Chrome プロフィールを他人が使える状態だと、その人も設定画面を開けます。Windows のログインにはパスワード/PIN を設定しておいてください

## うまく入らない時

サイトの作りによっては判定できない欄があります。その欄は手で入力してください。
郵便番号から住所を自動補完するサイトでは、補完によって住所欄が上書きされることがあります。

### 診断情報のコピー

拡張機能のアイコン →「うまく入らない時：診断情報をコピー」を押すと、そのページの欄の作り（欄の名前・見出し・選択肢・ボタンの種類）と、
拡張機能がそれぞれの欄を何だと判定したかがクリップボードにコピーされます。入力済みの値やプロフィールは含まれません。
